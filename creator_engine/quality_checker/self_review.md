# Creator Self Review

生成后的六阶段流程：

`Context Loading → Scene Planning → Draft Generation → Self Review → Revision → Memory Commit`

Self Review 至少检查：

- Continuity：时间、地点、人物状态、世界规则、伏笔。
- Character：行为、心理变化、欲望、价值观和代价。
- Literary：主题、意象、声音、情绪余韵和过度解读。
- Commercial：节奏、承诺、主动行为和章末动力。

审核结果进入 Decision Engine。作者确认前只保存 draft、review 和 proposal，不更新 canonical memory。
