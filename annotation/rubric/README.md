# Annotation Rubric

评分采用 1/5/10 锚点，并允许中间值。所有分数都要引用证据和一句理由。

## 人物深度

- 10：行为由复杂心理、经历、价值观和矛盾共同驱动，选择承担可见代价。
- 5：有明确动机，但矛盾、压力或转变节点不完整。
- 1：角色只服务剧情，缺少独立欲望和可解释选择。

## 结构质量

- 10：目标、冲突、行动、转折和后果形成闭合因果链。
- 5：主线可理解，但推进、钩子或场景功能有缺口。
- 1：事件堆叠，角色选择无法推动后续。

## 文学质量

- 10：主题、人物、意象和语言互相强化，同时保留多义性和余韵。
- 5：有可感知的主题或风格，但机制不稳定或证据有限。
- 1：只有剧情概述、抽象评价或未经证据支持的过度解读。
