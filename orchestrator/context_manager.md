# Context Manager

为长篇小说采用三级上下文，控制成本并保持可追溯性：

- **Level 1 当前章节**：完整加载当前章节/场景、当前任务和相关实体；所有局部判断必须基于此层。
- **Level 2 当前卷**：按角色、事件、伏笔、时间线和状态筛选加载与当前任务相关的章节摘要及证据；不默认加载整卷正文。
- **Level 3 历史检索**：只检索与当前问题相似的旧证据、已关闭伏笔、历史冲突和快照；返回引用和相似原因，不把检索结果当作新事实。

上下文请求格式：`{level, reason, query, entity_ids, max_items}`。Context Manager 应优先返回摘要+证据位置，只有 Agent 明确需要时才扩展原文。每次任务记录实际加载的层级和引用，便于复现。
