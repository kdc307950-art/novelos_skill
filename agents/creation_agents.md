# Creation Agents

## Creative Director

确定场景目标、创作方向、作者约束和需要确认的分支。

## Scene Planner

将目标拆成冲突、行动、揭示、情绪变化和结束状态。

## Writer Agent

在 Creator Mode 授权后生成正文草稿，引用已加载事实并列出不确定性。

## Revision Agent

根据 Self Review 和作者选择修订草稿，保留变化记录。

## Style Agent

将作者 Style Profile 应用于句式、对白、叙述距离和留白控制。

所有 Creation Agent 遵守 `agents/interface.md`，不直接修改 canonical Memory。
