# GUI Guide

GUI 是作者和编辑使用的工作台入口。它与 CLI、MCP 共享 Runtime 和 Memory。

```bash
python interfaces/gui/server.py
```

打开 `http://127.0.0.1:8765`。

| 页面 | 用途 |
| --- | --- |
| Workspace | 项目状态、故事阶段、人物/事件/伏笔数量 |
| Editor | 粘贴章节并提交分析任务 |
| Memory | 查看当前状态和证据入口 |
| Report | 查看编辑发现和修改方向 |

GUI Alpha 适合作者、编辑和策划；云同步、多人协作和商业账户不属于 Alpha 范围。
